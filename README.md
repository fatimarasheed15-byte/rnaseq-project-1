# rnaseq-project-1
Reproducible RNA-seq differential expression analysis of a public GEO dataset using R and DESeq2: QC, PCA, differential expression, and pathway enrichment.
# About Me #
I'm a biotechnology graduate who understands the biology behind the data. I'm building the skills to turn biological questions into clean, reproducible analyses, using R, Python and AI tools to work faster while checking every result against the evidence. This repository is my first complete RNA-seq project: from raw counts to differentially expressed genes, pathways and a biological interpretation.
